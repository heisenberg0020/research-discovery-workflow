# Optional integration with Phase 0 capabilities

The workflow is self-contained: its scientific requirements can be carried out with the host's available public search, lawful document reading, static code inspection and file tools. It does not require a particular model, API, plugin or installed skill set.

Its development was informed by the seven Phase 0 capability categories in [lingzhi227/agent-research-skills](https://github.com/lingzhi227/agent-research-skills). These skills are **not bundled** here. This mapping is an integration guide, not a claim to reproduce their scripts or grant a license to third-party content.

| Optional skill | Useful role in this workflow |
|---|---|
| `deep-research` | Field and method coverage, full-text understanding, synthesis and rereading |
| `literature-search` | Complementary searches, metadata/original-source discovery, backward/forward/contrary searches |
| `literature-review` | Competing perspectives, explanation comparison and evidence-based discussion |
| `github-research` | Targeted checks of official implementations, assumptions, data eligibility and reuse |
| `idea-generation` | Concrete relation/operation alternatives and substantive refinement |
| `novelty-assessment` | Claim-scoped precedents, equivalence, competitors and opportunity boundaries |
| `research-planning` | Mechanism-preserving conditional plans and staged discriminating validation |

Use only capabilities relevant to the task. If the user explicitly requests all seven, integrate all seven where they contribute, avoiding seven redundant searches/reports. Read selected installed skills and required references fully before using them. Resolve conflicts against the current user request and this workflow's intended scientific behavior rather than silently combining inconsistent templates.

In particular, do not turn fixed paper/repository counts, I/F/N scores, binary novel/not-novel labels, role-play consensus or preservation of an initial idea into mandatory selection rules. Treat close-neighbor relevance, competitive strength and sufficiency separately. Expand an operation or explanation before judging it; do not outsource ideation to a score.

Do not silently install upstream dependencies, change global settings, read credential files, activate paid APIs or expand execution resources. Follow current authorization and actual host capabilities. A relevant capability that is unavailable can be performed with a documented native-tool fallback; an unavailable tool is not proof that a scientific source or question is inaccessible.
