# v1.2.0 — 首次上手与完整教学案例

科研 Workflow 仍为 **v1.0.0 字节冻结**。本版只完善仓库使用与教学呈现，不改科研阶段、原启动提示词、Skill 引用或准备器。

## 第一批：首次使用路径

- 中英文安装与兼容指南，英文中性 brief。
- 先选择并核对 Python 3.10+ 可执行命令，再预览安装。
- 只有下载资产也能在解压前核对 ZIP 和清单摘要，解压后可用包内核验工具；不需要源码 Git 仓库。
- 可选只读加载检查，以及保留完整引用的显式读取备用入口。不把文件安装成功说成客户端已加载。

## 第二批：完整、可核对的教学案例

[截止前信息价值案例](../../examples/deadline-information/README.md)使用原始论文链接和明确设定的有限决策模型，展示 Q0–Q7 的构建、原 Q5 快照、实质纸面修补、强比较器、资源估算与洞察报告。[English walkthrough](../../examples/deadline-information/README_EN.md)提供英文阅读路径。

[双轮延迟交接](../../examples/deadline-information/two-pass.md)展示第二轮先形成独立版、完成 Q5-R，再按指定清单接收第一轮的过程；合流可以保留第一轮更好的构思。

案例是**作者编写的教学重构，不是两次真实独立运行记录**。没有执行实验、模拟、模型调用或形式网格枚举；不宣称论文新颖性、实际性能或 Workflow 效果。案例文件不装入 Skill，也不成为强制模板。

## 更新与验证范围

已安装 v1.0.0/v1.1.0 Skill 的科研内容与本版相同，无需为获得新研究能力覆盖个人安装。旧标签与发行包继续保留。

本地 **66 项测试通过**，仓库链接、版本和冻结校验通过；13 个冻结文件对 v1.0.0 的直接 Git 比较无差异。新增 ZIP 消费者命令路径测试在临时目录中完成，覆盖解压前摘要校验、无 Git 源码的包内核验、无写入预览、安装字节保持与空目录准备。实际测试结果和限制见[验证记录](../VALIDATION.md)；远程 CI 以 [Actions](https://github.com/heisenberg0020/research-discovery-workflow/actions) 为准。

加载检查提示词是新增使用说明，**不是已完成的真实客户端加载认证**。仓库测试、教学案例和冻结校验均不证明选题质量、隔离能力或两轮优越性。
