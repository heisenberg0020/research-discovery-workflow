## 仓库验证

本地 macOS / Python 3.13.13：**81 项测试通过**，公共链接/版本/冻结核对通过，13 个冻结文件对 v1.0.0 的直接 Git 比较无差异。新增 13 项证据导出合成测试和 2 项公开文档范围回归；它们不运行客户端或实验。

曾发现旧链接测试误把忽略的本地原日志当发行文档；修复为明确公开范围，并将嵌套公开证据纳入检查。另在实际导出前发现路径脱敏可能误改 `(x−20)/5` 的除号，缩小为已知路径根、添加公式原样回归；没有重新运行科学调用或改其答案。两项都是外层工具修复，不是 Workflow 变更。

发行包仍只包含已提交公开文件，不含原始本地 logs、个人科研目录、缓存或凭据。远程 CI 按[实际 Actions 回执](https://github.com/heisenberg0020/research-discovery-workflow/actions)判断，不由配置推断。旧版本与标签保持可用；已安装 Skill 无需为新科研能力覆盖安装。
