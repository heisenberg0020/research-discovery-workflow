# v1.1.0 — 仓库呈现与分发完善

科研 Workflow 保持 **v1.0.0 字节冻结**；本版不改造科研流程，不增加阶段、模板门槛或实验授权。

## 新增与整理

- 原创 SVG 首页横幅、双语使用入口与文档导航。
- 安装、架构、兼容说明；中性兴趣文档与明确标为虚构的规划片段。
- 可选标准库安装器：支持无写入预览、自定义目标，拒绝覆盖已有安装。
- 冻结文件、相对链接和资产检查；安装与分发测试；公开 CI。
- 从干净已提交源码构建版本 ZIP、文件清单与 SHA-256 校验。
- 贡献指南与最小公开问题反馈入口。

## 迁移

现有 v1.0.0 Skill 的研究能力与本版相同，不需要替换个人安装。当前安装器不会自动覆盖旧版；可以先在新目录试装。

旧 v1.0.0 标签与发行资产保留，新版不会覆写它们。冻结基准及核对方法见[冻结说明](../FROZEN_WORKFLOW.md)。

## 验证范围

本版增加的是仓库工具与文件验证，不是科研实验。本地 **62 项测试通过**，仓库检查与 Skill 元数据检查通过，13 个冻结文件的摘要和对 v1.0.0 的直接 Git 比对均一致。GitHub CI 以实际 [Actions](https://github.com/heisenberg0020/research-discovery-workflow/actions) 回执为准。首次版行为试走的限制保留在[验证记录](../VALIDATION.md)。

另在 macOS / Python 3.13.13 的独立临时目录完成新用户命令试走：预览无写入、安装字节一致、重复安装拒绝覆盖、已安装准备器生成空工作根。不代表客户端自动加载或上下文隔离已验证。

不宣称提高选题成功率、论文新颖性、两轮优越性或宿主隔离能力。安装、目录准备、计划就绪和实际研究执行仍是不同事项。
