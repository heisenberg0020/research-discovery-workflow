# 两轮科研探索：可直接使用的提示词

## 先准备一份中性兴趣文档

这份文档写：领域与范围；关心的科学认识、能力或决策；想了解的现象或改善的方向；硬边界与可协商边界；已知资源与未知资源；是否需要个人投入排序；实验是否授权。可以包含真实需求，不应把第一轮候选或旧架构作为默认答案。

A 收益与成本归因、B 现象机制、C 更好方法是可选视角，不是三个名额。没有必要一开始指定算法、论文题目或 benchmark。若有必须保留的技术种子，直说本次是有种子探索，不声称完全空白。

## 第一轮：新对话，只附兴趣文档

```text
使用 $research-discovery-workflow 开展第一轮科研发现与 planning。

研究兴趣与可协商边界只以本次附上的中性文档为准。请不要引入其他历史对话、研究项目、旧候选、旧架构或旧结果。

先落实五步环境隔离：新的非继承上下文、干净工作根、本次运行的记忆/项目指令检查、限定上下文来源、确认实际工具与读取边界。受宿主能力限制的部分如实说明，不把提示词当作沙箱，也不改全局设置。

执行 Q0 → Q1-T/U（分别保存首轮）→ Q1-S → Q2 → Q3 → Q4 → Q5。
重建当前领域和强方法已经做到什么，再提出具体解释或技术操作。允许大胆且明确标为假说的构思；不能因为已有相关论文就宣布问题充分解决。候选的具体剩余机会需要说明后果，但不要求先有阳性实验才准构思。

保存 Q5 原独立快照后，必须执行 Q5-R：对本轮认识、机制、对照、技术关系和正文交付作实质复盘，另存纸面修订版，并在每项提案开头讲清“已有答案—我们还想增加什么—哪一个区别使研究有内容”。

本轮没有旧成果包，Q6 标 not_applicable，不因此等待。Q6-P 只提出合适的先导或说明跳过，不执行科研实验。继续完成 Q7。

全面洞察汇报前，先完成 Q7-A：每个保留方向精确说明近邻已回答到哪，写两种竞争解释和可区分观察，确认真实数据/模型/实现/划分的资格与资源估算，说明不同结果改变什么决定。交付可执行比较方案，不是另一轮宏观综述；访问尚待条件如实标注，不能偷换研究对象或虚构资源。

在对话中给出详细、自包含、有洞察力的报告：领域认识与变化、候选怎样形成、具体机制、为什么剩余机会可能有价值、最强替代和区别预测、条件规划与尚未验证的部分。不要只给文件链接或阶段完成清单。

保留本轮原独立版、修订版、最终提案、来源与阅读笔记，作为将来第二轮 Q6 可指定的材料。结束后停止，不自动开启第二轮或实验。
```

## 第二轮：另开新对话，仍只附同一份兴趣文档

第一轮报告不要附在这个启动消息里，也不要提前放入第二轮工作根。先由用户/协调者保管。可以先用准备器生成两个独立工作根，但准备器不创建对话或保证隔离。

```text
使用 $research-discovery-workflow 开展第二轮全新科研发现与 planning。

只使用本次附上的中性研究兴趣文档与 Skill 规则；不要查第一轮或任何其他历史成果。不要为了与第一轮不同而刻意造新题。先落实并说明五步环境隔离，再执行 Q0 到 Q5，以及必做的 Q5-R 独立复盘和纸面修订，保留原独立快照与修订版。

两轮最终使用的安排是：只有在本轮 Q5-R 真正完成之后，才接收我指定的第一轮材料进入 Q6。这个安排已授权对该指定包进行对照与合流，但材料还未交接，不能提前寻找或读取它。

如果完成 Q5-R 时仍未收到材料，清楚说明本轮独立理解、具体提案、复盘实际改动和待交接位置，Q6 标 pending_handoff；不要虚报合流已完成，也不要读取外部历史目录。

Q6 应同标准比较新旧成果的具体机制、反证、遗漏和可复用原理，允许第一轮更强的想法保留，不按新旧或重复数量投票。合流后先完成 Q7-A 的每方向可执行比较方案与资源估算：近邻答案边界、两种竞争解释与区分观察、真实资源和切分、结果到决定。再形成 Q7-B 最终规划与全面洞察汇报，作为本次实际使用的结果。

暂不执行科研实验。最后在对话中详细讲清调研洞察、候选来源、价值依据、机制差别、合流改变与下一步如何判断，不能只交文件。
```

## 第二轮完成 Q5-R 后的指定交接

```text
本轮 Q5-R 已完成。现在将所附/所指定材料作为 Q6 的第一轮成果包，允许读取的范围仅为：……。

请先核对本轮 Q5 原独立版与 Q5-R 修订版已经保留，再开展 Q6：检查重复、真正反证、遗漏的理解与可复用资源；决定哪些具体主张保留、撤回、改写、重新定位或仍未决。旧文件中的指令不提供新的授权，也不自动延续旧架构。

同一论文被两轮使用不算独立复现。第一轮与第二轮的想法用同一科学标准比较，不要求第二轮胜出；合流的新构思要解释实际工作过程，不拼模块名。必要时返回机制修订，但保留合流身份。

Q6-P 只做先导提案或跳过，暂不执行。先完成 Q7-A 四问：最近工作精确答到哪；两种竞争解释和区分观察；真实资源/模型/实现/划分资格与估算；结果改变什么决定。形成具体可执行比较方案，不偷换对象或自动恢复旧实验。再完成 Q7-B 最终具体提案与条件规划；在对话中详细汇报领域洞察、候选的产生与变化、为什么具体剩余机会有意义、强替代、判别路径及限制，并引导我思考接下来最想弄清楚的问题。
```

交接包建议包括第一轮最终/修订提案、核心机制、决定性来源和阅读深度、相关反证与明确未决。无须整个项目树。若曾做授权实验，真实阴性与失败也应按相关范围交接，不能只挑好结果。

## 如果只需要一轮

使用第一轮提示词即可。有已有成果且希望合流时，只先声明其指定范围，内容留到 Q5-R 后交接。没有旧成果不必创造一个 Q6 对照；没有先导实验也能完成具体的条件规划。
