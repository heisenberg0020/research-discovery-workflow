# 实质复盘：学到了什么，尚未证明什么

本页是仓库维护者对实际产物的复盘，不是另一次独立科研评审。协调者读取了第一轮提案、复盘、修订及接续比较/来源记录，并抽查决定性论文、公式接口、官方实现和资源说明；没有把全部 worker 阅读声明转换成自己的全文阅读声明。

## 1. 从中性问题到一个具体关系

输入开放讨论随时间变化的预测不确定性如何支持可靠决策。第一轮最后主要聚焦在线 conformal 集合与 predict-then-optimize；这是真实形成的收束，不代表完整覆盖预测不确定性研究。T/U 首轮分开保留，但共享论文不提供两份独立科学证据。

最重要的收束是区分三个问题：集合是否覆盖真实量；集合是否改变动作；动作是否改善实际成本。最近既有工作已经给出有限动作集、盒形不确定性下的精确切换几何：名义动作最小化预测成本，robust 动作增加按半径缩放的尺度成本；在唯一名义动作、非边界等条件下，切换由半径是否越过几何临界值决定。不能把这个已有答案包装成新贡献。[既有切换答案，§4](https://proceedings.mlr.press/v329/dronavajjala26a.html)

但切换不等于损失。修订提案保留了动作差方向上的分解：实际相对成本等于发行前已知的名义成本差，加上事后才可见的方向残差。相同覆盖和相同切换可以对应相反的实际损益。这个纸面关系澄清了研究对象，没有证明新方法有效，也不否定最坏情形优化的原目标。

由此形成的具体候选不再是“改进切换指标”，而是：**在当前预测、几何和简单方向历史之外，过去的半径响应与方向残差，是否仍提供未来损失信息？** 严肃替代是当前信息与强简单历史已经足够；采用简单方案也是有意义的结果。

原稿、变更链和确切机制见[原 Q5](../../validation-runs/2026-10-06-public-topic/evidence/PASS1-CLOSING/output/q5-original/REPORT.md)、[另存修订](../../validation-runs/2026-10-06-public-topic/evidence/PASS1-CLOSING/output/q5-repaired/REPORT.md)及[局部洞察说明](../../validation-runs/2026-10-06-public-topic/evidence/PASS1-CLOSING/output/final/CHAT_REPORT.md)。这里保留的是待验证提案，不是新颖性认证。

## 2. Q5-R 确实改变了操作，而不只是加风险说明

第一轮 fresh 评审提出的修补主要涉及五类具体问题：控制器极端输出如何落到有限执行域；无穷临界值和边界条件；几何身份、信息增量与政策价值不可混成一条因果结论；可用时间、历史映射和划分；强 conditional predict-then-optimize 对手应如何匹配生成器与集合几何。

另存修订和同轮接续把其中几项落成了可执行语义：

- 先保存发行集合，用它计算实际反馈，再更新控制器；有限裁剪变体不自动继承无限/空集合版本的保证。
- 固定当期参考方向，对已到达的完整历史残差重新投影；不能把不同历史方向上的损失直接当同一种信号。
- 比较强当前输入加简单历史与等维候选历史，匹配 learner、容量和预算；相互等价的两种 loss 不重复算两份证据。
- 开发期先按覆盖条件锁定配置，测试期不重选有利 frontier；裁剪主导、覆盖不能匹配或标签不足时保持无识别结论。
- 明确同生成器的 union 与 bounding-box 比较；线性目标中集合及其凸包的支持函数相同，所以不能把共同几何约束的收益单独归因于“非凸性”。已有 CPO 本身是必须认真面对的强答案。[CPO 方法与条件，§3–4](https://www.ambujtewari.com/research/patel24conformal.pdf)

这支持“本例发生了实质纸面修补”，不支持“修补已取得真实科研增益”。细节和争议保留在[Q5-R 评审](../../validation-runs/2026-10-06-public-topic/evidence/PASS1-CLOSING/output/q5-review/REVIEW.md)与[Q7-A](../../validation-runs/2026-10-06-public-topic/evidence/PASS1-CLOSING/output/final/Q7-A.md)。

## 3. 为什么仍不能宣称主计划就绪

资源核对没有停在“有 PeMS 下载入口”。主比较需要固定 210 天单版本成本档案、该期方向及 connector 映射、每个 OD 至少两条逐边有成本的合格路径，以及真实发布时间/版本账本。官方资料提供若干必要字段和历史配置入口，但这不等于本案例已拥有满足全部条件的数据；当前表不能替代历史映射，观测时间也不等于发布可用时间。[官方资源入口](https://dot.ca.gov/programs/traffic-operations/mpr/pems-source)、[官方处理说明](https://cagov.github.io/caldata-mdsa-caltrans-pems/data/data-transform/)

用定稿档案加人工延迟只能回答更窄的代理回放问题，不能替代原自然信息时序。比较工作量、存储和强生成器需求已给公式/范围估算，但没有编造 CPU 小时、访问权限或已下载状态。12 个 OD 共享成本流、60 测试天约 8.6 周，也不能冒充跨环境独立复现。

因此第一轮是“提案形成、局部证据与比较具体、主资源仍未合格”。Q7-A 整体 incomplete，完整 Q7-B 没有完成。原定协议的第一轮完整 Q7 目标未达到，后续若使用这份包必须明确它是**部分结果交接**，不能悄悄把计划写成无扰动的完整双轮成功。
