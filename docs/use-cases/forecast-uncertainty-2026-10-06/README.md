## 本例为什么仍值得保存

它展示了规划中的实际内容变化，而不只是文件齐全：从集合覆盖/动作切换走向实际损失问题；让强既有答案成为比较对象而不是回避构思的理由；Q5-R 修补确切操作；资源检查阻止了用方便的代理回放偷换主问题。

同时，它暴露出宿主状态工具也可能带入历史结论。第二轮没有继续生成受污染的“独立”成果，这保留了失败的真实性，但**没有证明隔离成功**。恢复或另开上下文需要明确处置，不通过悄悄重抽抹去失败。
