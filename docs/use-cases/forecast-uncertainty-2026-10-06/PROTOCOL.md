# 公开专题使用案例：执行边界

本案例由用户在 2026-10-06 授权作为第五批仓库建设开展。它是实际公开材料的调研与规划案例，不是单元测试中的虚构 fixture，不是科研效果实验，也不用于证明 Workflow 成功率或双轮优越性。

科学 Workflow 使用字节冻结的 v1.0.0。第四批只修补外层工具与说明；案例结果不反向修改 Workflow。

## 输入与时序

两轮使用同一份 BRIEF.md 和相同冻结 Skill，在各自新工作根开展。研究上下文以新建、不继承前文的 worker 为单位；协调者已知本仓库开发历史，但不向研究 worker 提供旧候选、测试答案或预期科学结论。

第一轮从 Q0 至 Q7，Q6 为 not_applicable。第二轮从 Q0 至 Q5-R，完成后停在 pending_handoff。协调者先读取其原稿、复盘及修订内容并保存摘要，再复制第一轮指定的提案、比较方案与来源说明。第二轮之后的 Q6/Q7 明确是 informed/merged，不再次称为独立版。

路线首轮与 Q5-R 评审优先使用不继承父对话的 worker；若工具/并发限制使其不可用，记录实际暴露与自审限制，不编造独立性。目录与指令边界不是文件访问沙箱，不能证明全局记忆被清除或所有旧目录被拒绝读取。

## 观察与保存

保留两轮原 Q5、Q5-R 修订/复盘、来源与阅读深度、具体比较和最终报告。记录哪些来源或推导改变了判断、旧成果交接后的主张变化，以及真实未解决问题。不会按候选数、论文数、固定分数或正面结果筛选答案；低价值、重合、撤回和未就绪均保留。

文献出处以实际 consulted 的原始链接与位置为准；不复制受限全文，不把摘要阅读写成全文阅读。协调者复核决定性来源和科学机制。若执行失败，保留现场并报告；不重抽输出求更好的结论。

本案例不运行科研实验或付费 API。公开材料获取与只读静态检查属于本次授权；数据适用性、计算和访问估算是规划事实/条件，不是已执行结果。

## 完成与交付

Q7-A 先形成主问题的具体比较与真实资源评估，再做自包含的洞察汇报；若主机制/资源仍未确定，只记录局部进展，不冒称完成。最后另做仓库案例复盘，区分研究洞察、执行行为证据和未验证能力。不会把这一例外推为跨领域有效性。

这份执行协议供维护者核查，不作为研究 worker 的候选筛选答案；worker 接收中性 brief、冻结 Skill 与对应启动请求。
