# 逐观察语义复核

[汇总](README.md) · [既定范围](PROTOCOL.md)

执行后由另一个 Agent 子任务只读核对输入、实际事件、最终对话及保存产物，主协调者再核对关键公式与保留摘要。这是同一系统环境中的语义复核，**不是盲评、独立模型科学评审或形式证明认证**。评审任务没有重新调用测试执行器，也没有修改其答案。事件号指原 JSONL 行号，公开 `transcript.jsonl` 用 `source_line` 保留对应位置。

`demonstrated` 表示这份记录实际支持观察；`inconsistent` 表示存在具体相反行为；`unobserved` 表示证据不足；`not applicable` 表示该调用不承担该观察。证据不足不自动算已违反，也不自动算通过。

列出的科学内容和阶段判断未见 `inconsistent`，但不据此给整体成功率或隔离认证。B1 的全部 Q0–Q7 只在一个简小的理论对象上试走；另外三类是特定晚阶段行为检查。案例与冻结指令的已知要求相配，不能据此推断陌生学科中的可靠性。

局部命令问题保留：L0 e7 有临时缓存写入被拒绝警告；B2-pre e11、B4 e5 的 `rg` 因输出目录未建返回 2，B3 初次清单也有同类错误。随后读取/建档正常，各主调用退出 0、无超时。这些不是整次科学失败，也不应删成“全程无错误”。

原始和公开副本的用量字段、摘要及遗漏以各 `usage.json`、`export.json` 为准。cached 不重复相加；子代理独立用量没有闭合，不能称完整真实成本。公开证据不发布隐藏 reasoning。
