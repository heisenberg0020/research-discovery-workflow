# 经验性界面收益：部分比较规划

本文件仅基于两份虚构输入和本地 Skill；没有文献检索、真实资源核验或经验结果。研究对象保持为：设备操作员使用带噪温度测量进行阈值决策时，重构原单位读数界面相对标准分数界面是否减少动作错误和任务负担。

既有局部答案是 q=(x−20)/5、r=20+5q=x；阈值 r≥τ 等价于 q≥(τ−20)/5。这只证明指定变换、非零尺度、精确算术下的表示等价。拟研究的新增关系是相同观测信息如何影响操作员的解释和行动。如果原单位表示在真实任务中降低有意义的错误或负担，贡献是界面价值证据，不是传感器精度改进。直接显示 x 是严肃且更简单的竞争方案。

## 1. 最近答案的边界

已读答案只有 formal-subproblem.md 的仿射推导，无可引用的真实近邻论文或设备研究。它解决表示可逆性与确定性阈值等价，未解决人的行为、噪声校准、真实状态标签或收益大小。不能据此主张新颖性或既有标准分数界面失败。标准分数显示和直接原始单位显示都必须保留为比较对象。

## 2. 核心比较与竞争解释

候选三组：S 显示 q；R 显示重构 r；X 显示直接原读数 x。三组来自同一测量源和共同设备事件，具有相同源时间戳、元数据、显示面积、操作机会与反馈时点。变换常数、原单位阈值和决策规则在各组同样可获得；S 不能被剥夺必要换算信息。避免 R 同时额外显示 q 或提供更多历史信息。R 与 X 应使用一致的单位标签、精度和舍入规则，检查实际数值路径，精确算术恒等式不自动保证有限精度界面完全一致。

解释 A：原单位表示降低阈值解释或换算负担，改善行动。解释 B：观察到的差异来自显示面积、信息、交互机会、培训或数据路径变化；也可能在严格匹配后无实用收益。匹配条件下 R、X 均优于 S 且 R 与 X 相近，与原单位解释收益相容，但不能单凭这一模式确认特定心理过程。R 优于 X 应首先检查舍入、时延、呈现和执行差异，不能归因于仿射重构增加信息。

候选分配为按操作员随机平行分组，避免同一人反复看到相同事件后记住答案。三组使用相同任务事件集合，平衡设备类型与事件顺序；独立记录操作员熟悉度，统一培训与反馈。若真实设备事件不能安全、有效地供三组匹配比较，此设计须重做，不能悄然换成合成温度任务。是否可使用真实设备的时间戳记录回放，须先确认其保留现场决策信息与任务负担；回放结果不能自动外推到实时设备操作。

决策时刻只能使用当时可见信息；事后状态参照仅供标注。主要错误参照须由合格场景确定：真实状态阈值、采取动作的允许时窗、误动作/漏动作定义及噪声区间内的不可判定规则。未取得可靠参照前，不生成错误标签。辅助指标是按当前显示读数应采取动作的规则错误。两者分开，避免把遵守带噪读数规则误称为正确处理真实设备。

主要效应对象为目标操作员总体中 R 相对 S 的动作错误率差；同时报告任务时间和预先定义的操作次数作为负担指标，检查速度与错误的权衡。X 对 S 判断原单位表示是否足够，R 对 X 判断重构路线是否有额外价值。保留操作员和设备事件的重复相关性，避免把每次动作都当独立样本。效应区间、实际意义阈值和多指标决策规则须在获得场景信息后、看到结果前冻结。行为收益即使成立，也只能在已检验任务与人群范围内解释。

## 3. 资源与实际可执行性

当前没有具名且合格的人群、机构、设备、仪器流、接口实现、噪声校准或任务记录；没有核验的公开数据。此处属于资源未识别，尚不满足“资源已合格但待访问”的条件成熟度，Q7-A incomplete。

后续资源资格工作需要：明确设备场景及阈值后果；识别合法使用的操作员群体与准入规则；核验仪器量程、单位、采样时钟、噪声校准和状态参照；确认三组比较及记录方式可行；提供接口版本与信息可用时点；取得使用权限、人员参与与设备操作的必要许可。需要的记录字段包括操作员匿名标识/资格、设备事件标识、测量 x 与时间戳、参照状态及质量、阈值与动作时窗、显示条件/版本/实际显示值、动作与时间、交互次数、训练或反馈暴露。记录获取尚未授权也未执行。

若有历史数据，须核验人群覆盖、真实决策时信息、动作标签、重复用户、任务分离、许可和访问；只有传感器读数没有界面条件与人类动作，不能回答界面收益。开发任务与最终评估应按操作员及设备事件隔离；冻结接口后再作最终比较，避免借最终结果调整呈现。

资源包络仅能给依赖公式：若每组 N 位操作员、每人 K 个合格任务，则三组共 3NK 次决策记录；人员时间约为 3N×(培训时间+K×任务及记录时间)，另加设备准备、校准、参照标注和分析时间。存储约为 3NK×单条记录大小，加仪器流；无需训练模型，新 API 调用数为零。N、K 和各时间/成本项均未知。N 需由最小有意义效应、基线错误率、人员/事件相关性、精度要求及可招募规模约束；这些参数没有测量或文档支持，不能给出可信人数、工期或预算。三组和不确定性需求均包含在未来估算中。

## 4. 结果将改变什么（预先规划，非结果）

- R、X 相对 S 均有有意义收益，且负担未恶化：支持原单位表示在该场景的价值；优先采用直接 x，重构仅在系统只传 q 时可能有工程必要性。
- R 与 S 差异精确落在事先定义的无实用收益区间：该场景可保留标准分数方案，收窄收益主张。宽区间的无显著差异不能作为等效证据。
- 错误下降但时间或操作次数增加：研究转为明确收益与负担的任务权衡，按设备后果判断是否值得。
- R 与 X 不同，或匹配失败：先排查数据路径、舍入、时延及容量差异，当前设计不能支持纯解释机制。
- 标签不可靠、事件未覆盖阈值附近、样本不足或执行失败：保持主问题未决，修订测量与资源方案；不判定方向失败。
