## 输入 → 表示 → 操作 → 目标 → 决策

- 输入：先验 `P(x=5)=P(x=9)=1/2`；行动 `a∈R`，单位与 x 相同；报告在选择行动前可见；成本 `c_q,c_b≥0` 在取得报告前固定。
- 表示一：`q=(x−7)/2∈{−1,1}`，其参数已知，既无噪声也无截断。
- 操作一：用已知逆映射恢复原单位，`x=7+2q`，然后令 `a_q(q)=7+2q`。
- 表示二：`b=1[x≥7]∈{0,1}`，定义及两点支持已知。
- 操作二：在这个支持集上，b 区分所有可能状态；`a_b(b)=5+4b`。
- 无报告操作：选择先验条件下的常数动作。
- 目标：最小化 `E[(a−x)^2]+c`。报告不改变状态分布；它改变可依据的信息与可采用的行动函数。
- 决策：先按总期望风险选报告或不报告，再按对应条件均值行动。

## 严肃的简单替代与完整纸面解

对于任一可用报告 r，平方误差可分解为

`E[(a(r)−x)^2 | r]=(a(r)−E[x|r])^2+Var(x|r)`。

因此充分的经典规则是 `a*(r)=E[x|r]`，最小期望误差为 `E[Var(x|r)]`。这不是需要新算法的场景：F1/F2 已给出计算所需全部条件。

无报告时 `E[x]=7`，`Var(x)=4`，故 `a_0=7`，风险 `R_0=4`。q 和 b 各自在两点支持上唯一确定 x，所以其条件方差均为零，分别有 `R_q=c_q`、`R_b=c_b`。最优总风险为

`R*=min{4,c_q,c_b}`。

若两种成本均严格大于 4，无报告严格最优；若某报告成本低于 4 且低于另一报告成本，该报告严格最优。两报告成本相同且低于 4 时二者并列最优；最低报告成本恰为 4 时，与无报告并列最优。成本为零的报告取得零总风险。

理性示例（成本值仅用于说明，并非测量）：`c_q=3/2,c_b=1/2` 时选 b，总风险 1/2；`c_q=1/2,c_b=3/2` 时选 q；`c_q=5,c_b=6` 时无报告；`c_q=c_b=4` 时三个选择并列。报告格式的复杂程度不能代替已给成本排序。

## 机制差异及其实际后果

q 的数值处于变换坐标，直接当作原单位行动会得到

`E[(q−x)^2]=((−1−5)^2+(1−9)^2)/2=50`。

这个 50 是一个错误决策规则的风险，不是 q 丢失信息的证明。应逆变换或求条件均值，才与原单位损失目标一致。q 的表示名或范围并不决定其行动价值。

b 通常形式上是阈值压缩，但在当前已知两点支持上，其两个纤维 `{x:b(x)=0}` 与 `{x:b(x)=1}` 分别只有 5 与 9。因此 b 与 q 在这个对象中具有相同的可行动信息；b 是有实质竞争力的简单替代，而非刻意弱化基线。若 q 更贵，则它在当前条件下被 b 严格支配；不能凭借标准化报告的名称宣称收益。

## 足够答案与可继续澄清的理论对象

本题已存在足够答案：条件均值规则、支持上可逆性的核查和固定成本比较。无需制造文献空白、增加模型、要求实验成功或引入经验结论。

可在后续阶段展开的解释对象是：对确定性报告 `r=f(x)`，零误差要求 x 在每个有正概率的报告纤维上保持常数；若同一报告合并不同 x，剩余平方误差就是 `E[Var(x|r)]`。这只是由上述分解推出的边界条件，当前 F1/F2 不含这样的碰撞。给定行动目标后，更一般的“有用”应以风险下降 `Var(x)−E[Var(x|r)]` 与成本比较，而非一律要求完整恢复 x。

在本对象中，两份报告的无成本信息价值均为 4；只有成本不同能改变二者的选择。后续解释应保留两个区别：表示变化与信息丢失不同；可恢复信息与值得购买信息不同。
