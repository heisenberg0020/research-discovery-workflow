# Q7-A 比较计划核对与纸面补全

本文件承接明确标为虚构的 input/current-packet.md 与 input/comparison-plan.md。证据仅限这两个输入及本地 Skill；本次只做纸面推导，未枚举执行、模拟、训练或调用外部 API。

## 1. 既有充分答案与机制

研究对象从一开始就是已知有限概率模型中的平方损失决策，非经验收益研究。状态 x∈{0,2,4}，概率为 1/4、1/2、1/4，动作 A={0,1,2,3,4}。先选报告选项，后按观察选动作；报告固定成本只在选项层加一次。

对报告 r 的确定性策略 δ，定义 J_r(δ)=Σ_x p(x)(δ(r(x))−x)^2+c_r。最强比较对象是每个选项全部可用策略的最小值。各观察分支可分别最小化条件期望损失，因而无需新算法。随机策略的目标是确定性策略目标的凸组合，不能低于其中最小值。

q=(x−2)/2，逆变换 a(q)=2+2q，输出均属于 A，风险 R_q=0。b=1[q>0]，P(b=0)=3/4；该分支中 P(x=0|b=0)=1/3，P(x=2|b=0)=2/3。条件损失为 (a−4/3)^2+8/9，在整数动作中 a=1 唯一最优，条件损失 1。b=1 时 x=4，动作 4 最优。故 R_b=(3/4)×1+(1/4)×0=3/4。

无报告时 E[x]=2，E[(a−x)^2]=(a−2)^2+2，最优常数动作为 2，R_∅=2。上述条件均值只是推导工具，不能把 4/3 当作允许动作。粗分支的不可消除条件方差 8/9 与整数动作附加误差 1/9 合成条件风险 1。

## 2. 需要区分的关系及对照

目标函数为 J_q=c_q，J_b=3/4+c_b，J_∅=2（无报告成本为零，沿用输入）。给定 c_q=4/5、c_b=1/5，分别为 4/5、19/20、2；精确报告较粗报告少 3/20，总目标最小。

仅看可恢复性或不计费误差会始终偏向精确报告；完整目标则取决于风险下降与成本增量。前者若被解释成“所有成本下精确报告总最优”，已被以下纸面关系否定，不应包装成仍然势均力敌的经验假说。若其只声称精确报告不计费风险最低，则完全正确，与成本敏感结论兼容。在给定成本点，两种说法选同一选项，单看选择不能区分其理由；成本边界才揭示区别。

固定状态、先验、动作、损失及两个观察函数，仅改变选项成本。完整最优区域（取通常非负成本）为：

| 最优选项，允许并列 | 必要且充分条件 |
|---|---|
| 精确报告 | c_q≤3/4+c_b 且 c_q≤2 |
| 粗报告 | c_q≥3/4+c_b 且 c_b≤5/4 |
| 无报告 | c_q≥2 且 c_b≥5/4 |

精确与粗报告的成本差门槛是 3/4，但仍须检查无报告。直线 c_q=3/4+c_b 仅在共同目标不高于 2 时构成最优并列边界；其上共同目标若超过 2，无报告胜出。c_q=2 与 c_b=5/4 分别还需检查第三选项。三者在 (c_q,c_b)=(2,5/4) 并列。用弱不等式保留所有平局，不强制唯一胜者。

## 3. 合格资源与工作量

全部资源已由输入定义：三状态质量函数、五动作集合、确定性观察函数、平方损失和有理成本；它们足以回答保留的主理论对象。无需数据集、设备、模型、许可、参与者、API 或测量装置，也无未确认的资源访问条件。工具是普通纸面代数与精确算术。

原计划的枚举规模正确：精确策略 5^3=125，粗策略 5^2=25，无报告策略 5，共 155。逐策略逐状态计算为每个成本对 3×155=465 个加权损失项，随后取最小值并加成本。这是未执行的派生工作量，不是时间或硬件估计。可先求一次各选项风险最小值，之后每个成本对只比较三个仿射目标，无须重复全部策略枚举。流式枚举仅需状态质量、当前策略及最小值；若存全部结果，需要 155 条记录，不提供字节数或运行时承诺。

## 4. 结果如何改变决策与计划状态

本次纸面推导与输入风险一致：保留已有条件期望损失最小化规则，并以成本区域解释选择。若未来获授权做确定性枚举且与这些风险不符，先检查观察分组、动作合法性、源单位、概率聚合和成本是否重复计入，不能立即解释成方法改进或经验反例。成本跨界则改变选项；无报告最低时采用常数 2；平局时保留所有最优选项。
