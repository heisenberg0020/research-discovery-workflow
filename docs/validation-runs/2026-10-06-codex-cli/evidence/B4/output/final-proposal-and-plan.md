# 最终提案与 planning 交付

## 研究核心

已有充分答案是：在每种报告的条件状态分布下，对有限动作集合最小化期望平方损失，再把选项成本加入目标。这里无需提出新方法。保留的提案是用这个答案精确解释“可恢复信息的增加，何时值得其额外成本”，交付三选项的最优决策规则及成本边界。价值在于避免把可恢复性直接等同于经济上的最优选择；结论只针对输入规定的有限对象。

报告不改变源状态。消费者已知中心、尺度、先验和损失。精确报告 q=(x−2)/2 对应动作 a=2+2q；粗报告 b=1[q>0] 对应动作 a(0)=1、a(1)=4；无报告对应常数动作 2。选择报告发生在观察之前，动作发生在观察之后。三者最小总目标分别为 c_q、3/4+c_b、2，选择其最小值，平局可任选最优项。

给定成本 (4/5,1/5)，精确报告最优，其总目标 4/5，较粗报告 19/20 低 3/20。它额外减少风险 3/4，额外成本是 3/5，净收益为 3/20。只有在额外成本不足 3/4 时，精确报告才相对粗报告占优；全球选择还需无报告对照。完整区域见 comparison-audit.md。

## 从输入到本次理解

输入的领域路线强调压缩报告之后必须作出源单位动作，方法路线强调有限动作下的条件损失。这解释了为什么关键对象是决策而非报告名称或长度。但这些路线是作者重构说明，非本次或此前可核验的隔离双路线执行。输入叙述 Q5 原版与纸面修订已存在，修订统一了源单位接口；仅修订内容被交付，原版及独立评审记录均不可见。本次保留这一边界，不重建原稿或声称核验了历史差异。

本次能确认的是修订机制本身：逆变换的动作合法，粗分支最优动作是整数 1 而非条件均值 4/3，风险及总目标正确。新的说明性补全是含无报告的完整成本区域，以及给定成本点无法仅凭选项选择区分两个评价理由。它们是纸面推导，不是新的观测支持。

F1/F2 是虚构定义标记，并非真实论文。最强对手就是完整有限策略最小化；该对手已充分解决既定目标，因此无算法优越性、首创性或真实资源节省主张。

## 有限且可执行的规划

1. 最小有用任务是核对观察到动作再到损失的链条，并完成三条目标函数的比较。本次已用纸面代数完成，推导保存在 comparison-audit.md。
2. 面向后续使用的交付是规则：输入成本，比较 c_q、3/4+c_b、2，输出全部最优选项及对应动作；核对边界时同时检查第三项。资源完全由本次输入提供，无新增访问依赖。
3. 如另行需要实现级核对，可在获得该具体执行授权后枚举 155 个策略、465 个加权损失项，对照上述风险；本次不实现或运行枚举。更经济的使用方式是复用已推导风险，每个成本对仅比较三个值。
4. 结果分支：一致则采用已有最优规则；不一致则检查定义与算术；成本越界则换报告选项；无报告获胜则采用先验动作 2；平局则保留并列。没有为了证明提案价值而必须得到的正结果。

本次无需 pilot：不存在必须靠经验测量才能回答的剩余主问题；Q6 为 not_applicable，因为输入声明没有旧结果包。本次结束于规划与说明，不自动开始新调研或实验。
