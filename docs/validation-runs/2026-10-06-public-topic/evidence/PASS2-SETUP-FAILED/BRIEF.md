# 研究兴趣与可协商边界

## 领域与范围

变化环境中的预测不确定性，以及预测区间、集合或概率输出如何支持可靠决策。以随时间到来的预测问题为主要情境；可以讨论其他有实质联系的情境，但应解释迁移条件。不预设具体算法、理论形式、模型架构或唯一瓶颈。

## 想弄清楚什么

了解这个领域现在重要的问题、已有答案与适用条件；理解方法实际上如何工作。由此提出有依据的具体研究解释、技术操作或理论对象，并形成能区分强替代的研究规划。既可以研究收益和成本来源，也可以解释重要现象，或改善明确瓶颈；不要求每类都生成一个候选。

## 硬边界

- 仅使用本次中性 brief、冻结的 research-discovery-workflow、当前轮新获取的公开原始来源与当前轮产物。
- 不引入个人历史项目、之前构思、既有实验、其他对话或另一轮结果，直至指定 Q6 交接。
- 只做调研、合法原文阅读、静态实现/资源文档理解、纸面推导和 planning。不执行训练、评测、模拟、数据实验或用户研究。
- 不安装依赖、不启用付费 API/远程算力、不修改全局设置。不把企业声望或论文数量当作重要性证明。
- 不承诺新颖性、SOTA、发表或总体效果。构造例子标明为解释用途，不能生成实验成绩。

## 可协商边界与资源事实

研究贡献类型和最终具体问题开放。理论与经验规划均可；资源未知可以成为明确条件，但不能用方便的子问题替换保留的主对象。公开论文、作者/官方实现、资源说明和可核对的实际应用报告可以使用。当前没有指定或下载数据，没有部署环境、合作方或实验设备，也没有科研实验执行授权。

## 本次使用

资料截止为本次实际检索日期。使用者希望两轮分别从同一中性输入开展探索；第二轮在独立 Q5-R 后才接收第一轮指定成果。两轮重复来源不算独立科学证据，第二轮不必更好，也不必选择自己的构思。汇报用中文，保留原始出处和机制细节。
