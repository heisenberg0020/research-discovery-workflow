# 示例：从输入到具体规划

示例只帮助理解输入和交付形式，不构成科研建议、结果或新步骤。具体要求以[冻结 Skill](../skills/research-discovery-workflow/SKILL.md)为准。

## 先给什么

复制[中性 brief](neutral-brief.md)并填写自己的领域、兴趣和边界。不要把整个旧项目或第一轮结果在启动时交给独立第二轮。

## 交付应该具体到什么程度

以下是**原创的虚构规划片段**，没有检索论文、确认数据集、运行仿真或验证效果。不能把它作为成熟选题或已完成 Q7-A 的报告。

### 模糊表述

“研究传感器信息的价值，增加一个自适应模块。”

### 更具体的构思片段

设一项决策必须在截止时间 `d` 前做出；可能购买一个传感器信号。问题不是信号平均是否准确，而是其信息能否在决策前到达并改变行动。

假设候选操作是：对在截止前收到的观察，按当前信息选择动作；未及时到达时使用既有信息规则。计划比较这套操作与使用相同可用信息的固定规则，并把未及时到达这一事件本身的作用单独区分。这里描述的是构思，不是改进已被证明。

### Q7-A 四问的示意处理

| 四问 | 示例需要补到的内容 | 当前示例状态 |
| --- | --- | --- |
| 最接近工作已答到哪 | 读原始方法，确定其时限、信息和决策条件 | 未提供真实来源，不能声称已读 |
| 还要区分什么 | 条件信号内容带来增量，还是到达状态/既有规则足以解释；写明匹配的信息与观察 | 仅有假说和控制思路，需展开 |
| 哪套真实资源能答 | 同时记录信号、到达时间、决策前信息与结果的合格资源，及匹配切分/成本 | 未找到；不能凭“某公共数据”称就绪 |
| 结果改变什么 | 内容确有额外价值则继续；简单规则足够则收窄；时限事件未出现则该测量无判别信息 | 仅是条件决策，不是实验结论 |

所以这个片段可以帮助理解“具体提出什么”，但没有完整资源和近邻资格，不能宣称全面 Q7-B 已完成。真正的工作需要使用实际检索证据与保留的主研究对象。

## 会保存哪些成果

准备器预留 `output/q5-original/`、`output/q5-repaired/` 和 `output/final/`，并创建 `RUN.md` 状态索引。这不要求每个小项另建文件；连贯报告中的阶段章节也可以。

最终应能理解已有答案、实际提案机制、具体价值条件、强替代、判别方案、资源资格与未验证部分。文件供核查，详细洞察仍应在对话里讲清。

真实行为试走的范围和限制见[验证记录](../docs/VALIDATION.md)。这个公开例子不是那几次试走的原始输出。
