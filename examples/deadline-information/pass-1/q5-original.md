# Q5 原始快照：故意保留的教学错误

**状态：脚本化原稿；公式错误；不能当作正确建议。**此文件作为展示 Q5-R 的固定版本，修正另存，不覆盖此处。未接收任何真实旧研究材料。

研究核心是解释有噪声信息在截止时间前的净决策价值，并区分到达状态和内容。本例从一开始只做理论解释。经典强答案是根据实际可见信息最大化预期效用；没有新方法或领域缺口声明。

设 `θ∼Bernoulli(1/2)`，`a,Y∈{0,1}`，`P(Y=θ|θ)=3/4`，收益为猜对所得的 1，购买成本为 `c`。到达事件为 `R=1[L≤d]`，截止前只能使用及时的 `Y`。普通信号的正确率价值是 `VY=3/4`，无信号是 `V0=1/2`。

**原始错误关系：**不论到达机制如何，都把有效净价值写成

`N_marg = P(R=1)·(VY−V0)−c`。

行动规则：及时则使用普通后验 `P(θ|Y)` 选择猜测；未到达则使用先验最优行动。因此“未到达”没有价值，到达状态仅仅决定能否使用内容。若 `N_marg>0` 则购买，等于零时无差异。

严肃比较器应是截止时实际观测 `Z=(R,Y if R=1)` 的全贝叶斯规则；这里仍错误地把它当作上述规则的等价写法。候选 B 计划比较 `Z` 与仅 `R`，但尚未计算分解。

拟议纸面比较：给出独立擦除和依赖到达的联合概率表，用同一效用和成本求两个规则，判断是否改变购买选择。资源为有限概率表与策略枚举；不需要模型、数据集或实际延迟日志。原稿已形成可审查机制，但主公式未验证，因此不是正确完整解。
