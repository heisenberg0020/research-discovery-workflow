# 截止时间前的信息价值：完整规划教学例子

这是**作者编排、公开、带批注的理论教学重建**。它以有限二元决策走通 Q0–Q7 的解释链，展示原稿中一个具体错误如何在 Q5-R 被修复，以及两轮如何在修复后交接。没有实际执行两个独立轮次，没有独立审查，没有模型 API、模拟、数据实验、私人研究资料或工作流效果验证。阶段文件记录教学逻辑，不能被当作“所有阶段真实运行过”的日志。

读者会得到一个实质结论：付费后“到截止时仍未收到”可能也是有价值的观测。`及时到达概率 × 普通信息价值` 在共同独立擦除等明确条件下成立；任意到达机制不能仅凭一个边际概率完成定价。完整贝叶斯是已有且充分的强答案，本例不宣称新理论、新领域缺口或比它更好的方法。

## 怎样阅读 Q0–Q7

**Q0：先锁定科学目标，别先锁定答案。**[简报](neutral-brief.md)从开始就把目标设为理论解释：何时可用到达率折扣、如何区分状态与内容价值。现实延迟数据未核验是范围事实，不是后来把实证研究改成理论的理由。[Q0–Q4 记录](pass-1/discovery.md)同时披露：这里不是新上下文，目录不能清空记忆或限制读权限；没有真实旧结果，所以第一轮 Q6 不适用。

**Q1-T / Q1-U：两个视角要产生不同的问题。**领域视角问截止时有什么可见、买信息为何可能改变行动；方法视角从“逐观测最大化，再求和”与独立擦除出发。记录分别保留了初始问题包与机制包。两段由同一作者编排，不能以两个标题声称初次判断彼此未暴露。

**Q1-S：综合要改变理解。**桥梁是“未到达”也属于观测分区：它可能改变先验，及时子群也可能改变信号模型。因此继续的问题不再只是估计到达率，而是核对实际联合分布和信息集合。没有制造两个视角支持同一个候选的计分或共识。

**Q2–Q3：形成两个具体对象。**A 研究折扣公式适用边界；B 研究到达状态与内容的价值分解。二者都用相同明确模型：状态 `θ`、猜测 `a`、信号 `Y` 为二元量，猜对收益为 1，固定成本为 `c`，截止事件 `R=1[L≤d]`；购买后实际观测为 `Z=⊥` 或 `(1,Y)`。没有信息时用先验行动；及时与未及时分支都有各自条件行动。最强比较器是所有 `Z` 策略的最大期望收益。

**Q4：经典答案可以保留。**全贝叶斯已有相同运算，因而不保留“新算法”身份，而保留解释任务。原始边际公式仍有错误，改标题没有解决它；让错误保留到审查节点是教学编排，真实运行不应故意推迟已知修复。

**Q5：保存可审查的原始主张。**[原稿](pass-1/q5-original.md)写 `p(VY−V0)−c` 并声称任意机制都成立；未到达回先验，及时使用普通后验。这是特意保留的错误示例，不是读者应采用的建议。完整运算、效用、时序和严肃替代都写在正文中，使审查者能定位问题。

**Q5-R：修复变量关系，而非增加免责声明。**[回顾](pass-1/q5-review.md)定位边际折扣、未到达回退与及时后验三处接口错误；[修订](pass-1/q5-repaired.md)给出完整表达式。令 `w_{θyr}=P(θ,Y=y,R=r)`，

`VZ = max_θ Σ_y w_{θy0} + Σ_y max_θ w_{θy1}`，

净值为 `VZ−V0−c`。第一项针对可见的未到达事件，第二项对每个及时内容取最优行动。若 `R ⟂ (θ,Y)`，直接代入得到 `VZ−V0=p(VY−V0)`；这是充分条件，不是必要条件。修订与原稿分别保存，未覆盖错误的历史版本。

以 `θ∼Bernoulli(1/2)`、信号准确率 `3/4`、`R=1` 当且仅当 `Y=1` 为例，未到达揭示 `Y=0`，及时揭示 `Y=1`，两种状态都使最优正确率为 `3/4`。所以真实毛价值是 `1/4`，边际公式是 `1/8`。成本 `3/16` 时，错误规则拒绝购买，完整规则购买。四个非零概率单元可手算，这不是合成效果实验。

B 用 `VR=Σ_r max_θ Σ_y w_{θyr}` 作状态控制，分成 `VR−V0` 与 `VZ−VR`。上述例子全部价值来自状态，及时内容无额外增量。另一个控制 `R=1[Y=θ]` 中，到达与状态独立，但及时内容完全正确；因此只检查 `R ⟂ θ` 仍不够。详尽推导与纯到达信息控制见修订稿。

**Q6 / Q6-P：按实际分支走。**第一轮没有旧结果，明确 `not_applicable`；没有必要开展试验，明确 `skipped`。[两轮脚本](two-pass.md)示意第二轮原稿、修订、Q5-R 后显式三文件交接及逐声明协调。规则未被工具强制，第二轮不被保证更好；综合保留更完整的第一轮方案。

**Q7-A：先让比较可执行。**[最终规划](pass-1/final.md)逐一回答最近答案、竞争账户、实际资源/工作量、结果决策。理论资源是八单元概率表与有限策略集合。81 核网格与 9,396 次加权收益贡献是由对象推导的未执行工作量；没有虚构运行时间、模型调用费或已获数据访问。该网格只检验指定有限点，不能代替一般证明。计划针对原先理论主目标，而不是把一个容易的子问题冒充实证计划。

**Q7-B：向读者交付理解，不止文件清单。**[可直接说给读者的报告](pass-1/final.md)解释错误如何改变购买选择，两个候选为何成为边界解释与价值来源解释，何时已有答案足够，现实迁移还缺什么。这里完成了教学推导、反例和比较设计；没有完成枚举执行、实证验证、两轮独立探索或工作流有效性验证。任何方案在相同真实模型与信息下都不能超过全贝叶斯最优值。
